# windy's roomba

- my personal discord bot, also used in my discord server
- not really meant to be used by others (but you can install it as user app & invite!)

## what does it do?

- `/fridge` commands are like canned responses or the `/tag` command in most bots
- `/i` are instance owner only
- `/image` for image conversions
- `/text` for text conversions
- there is an (dumb) LLM you can talk to, via `/roomba ask`. (source `roomba_gen.rs`, though the actual model is closed source)
- a lot more random things

## what ELSE does it do?

- it does my server things like verification
- check `include/config/*.json` for config examples
- although i really don't think you should use this for your server, its too specific
